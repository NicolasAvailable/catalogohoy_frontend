# CRM desktop — zoom, sin voz

Versión del 9 de septiembre de 2026. Captura real del viewport de Angular (1600 × 900), composición 1920 × 1200 a 30 fps, marco macOS y fondo azul, acercamientos con interpolación suave. Sin pista de audio.

Se muestran únicamente Alicia Méndez, Mateo Rojas, Lucía Torres y Diego Vargas, registros de prueba creados para tenant 1992 según ../seed-20260908.sql. Las demás filas y la identidad del usuario se ocultan en el navegador de captura mediante CSS; no se reemplaza la interfaz por mockups.

Recorrido: canales, configuración WhatsApp, bandeja, búsqueda, redacción sin envío, ficha con notas existentes y multimedia TikTok. No se enviaron nuevos mensajes ni se completaron autorizaciones externas. La respuesta previamente guardada se conserva.

`capture.json` y `frames/` contienen la captura de navegador con tiempos. `render.py` permite regenerar la composición y los zooms. La grabación no incluye el escritorio, login ni credenciales.
